# DevOps Week 02 - Git & GitHub Practice

A hands-on practice repository created as part of my DevOps learning journey, 
covering Git fundamentals, version control workflows, and GitHub collaboration basics.

## 📌 Overview
This project documents my Week 2 progress in learning DevOps concepts, focusing on:
- Git installation and configuration
- Repository initialization and management
- Committing, pushing, and pulling changes
- Working with remote repositories on GitHub

## 🛠️ Installation

1. Clone the repository:
```bash
   git clone https://github.com/prince6201/DevOps-Week02.git
```
2. Navigate into the project folder:
```bash
   cd DevOps-Week02
```
3. Ensure Git is installed on your system:
```bash
   git --version
```

## 🚀 Usage

1. Make changes to files or add new notes.
2. Stage your changes:
```bash
   git add .
```
3. Commit with a meaningful message:
```bash
   git commit -m "Your commit message"
```
4. Push to GitHub:
```bash
   git push origin main
```

## 🧰 Technologies Used
- **Git** – Version control system
- **GitHub** – Remote repository hosting
- **Bash/Linux Terminal** – Command-line operations
- **Markdown** – Documentation formatting

## 📖 What I Learned

## Workflow Followed
1. Repository create ki gayi aur initial files add ki gayi
2. Do feature branches banaye gaye: `feature/navbar` aur `feature/styling`
3. Dono branches me alag-alag changes kiye gaye
4. Pull Requests ke through dono branches ko `main` me merge kiya gaya
5. Ek merge conflict aaya jo manually resolve kiya gaya
6. Final code GitHub pe push kiya gaya
